# 3. Sujet fil rouge (à valider par l'enseignant)

## Intitulé
**Conception et réalisation d'un système d'information de gestion des patients pour le CSCOM « Espoir » de Bamako.**

## Description courte
Le CSCOM gère aujourd'hui ses patients sur papier. Le projet consiste à remplacer les registres par une application web simple, accessible sur le réseau local du centre, qui permet de :
- enregistrer un patient une seule fois avec un identifiant unique (numéro de dossier) ;
- retrouver rapidement son dossier et son historique de consultations ;
- enregistrer les paiements à la caisse ;
- produire automatiquement les statistiques mensuelles pour le district sanitaire.

## Pourquoi ce sujet
- Le problème est réel et fréquent dans les centres de santé au Mali.
- Il permet de traiter toutes les phases du cours : cadrage, conception (modélisation des données et des processus), réalisation, clôture.
- La taille est raisonnable pour un projet étudiant.
