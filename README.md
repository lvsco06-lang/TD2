## À retenir

Un SI est un ensemble organisé d'acteurs, de processus, de données et de technologies. Un bon cadrage évite la plupart des échecs de projet.

Cycle de gestion de projet : **Cadrage → Conception → Réalisation → Clôture**. Une exigence doit être vérifiable ; la démarche se choisit selon la stabilité du besoin et l'implication du client.
